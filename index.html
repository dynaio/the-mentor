Help & Documentation

Quick Start Guide

  1. Load a Scan: Drag & drop a NIfTI file (.nii or .nii.gz) or click "Browse Files"
  2. Navigate: Use the 3D viewer to explore the brain scan
  3. Analyze: Click "Analyze Brain Scan" to run AI detection
  4. Review: Check results in the right panel
  5. Export: Save your analysis as PDF or JSON

About The Mentor

The Mentor is an advanced AI-powered medical imaging platform for brain MRI analysis. Using state-of-the-art deep learning models, it can detect anomalies including tumors, Alzheimer's disease markers, and other neurological conditions.

Version: 2.0.0

Technologies: TensorFlow.js, AMI.js, Three.js
